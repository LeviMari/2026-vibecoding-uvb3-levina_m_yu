**Автор:** Левина Мария Юрьевна

## Проект: «Красивый бот» — личный ассистент по задачам и встречам

Telegram-бот [@itmoftmi_lmy_bot](https://t.me/itmoftmi_lmy_bot) превращает саммари рабочих встреч в систему: вытаскивает из них задачи, строит план недели, напоминает о сроках и отвечает на вопросы вроде «что мы решили по кэшбэку?», собирая ответ из нескольких встреч.

Идея выросла из личной боли: саммаризатор встреч у меня уже был, но его результат — текстовый файл, в который никто не заглядывает. Бот делает из этих файлов память команды.

Код сгенерирован с помощью ИИ (Cursor Agent) по подробному промпту-ТЗ, затем проверен, протестирован на реальных встречах и доработан.

## Интересные наблюдения

- **Агенту нельзя верить на слово.** Cursor сообщил, что прогнал синтаксическую проверку, но код не запускался: в двух файлах остались незакрытые кавычки.
- **Требование «не выводить токены в логи» агент выполнил только для своего кода.** Библиотека `httpx` печатала токен бота в каждой строке лога, это заметили только при чтении консоли.
- **Часть ошибок — в промпте, а не в коде.** Классификатор принимал «с коллегой обсудила» за вопрос о встрече, потому что не видел списка задач. Исправлено дополнением промпта контекстом и примерами.
- **Реальные данные находят то, чего не находят тесты.** Ошибка с кнопками проявилась только при загрузке четырёх настоящих встреч подряд.

- **Лимит Cursor закончился посреди генерации Лабы 2** — агент успел написать модули, а ревью и доработку пришлось делать другой LLM (Claude). Методичка это разрешает.
- **Лучшие улучшения пришли от использования на своих данных:** спрятанная настройка календаря в рабочем аккаунте, «Обед» как встреча, дубли саммари, тяжёлое оформление.

В Лабе 1 найдено и исправлено 11 проблем, в Лабе 2 — 7 по ревью кода и 8 по живому использованию. Подробности — в отчётах.
