# «Красивый бот» — личный ассистент по задачам и встречам

Telegram-бот на Python (`python-telegram-bot` 21, async). Принимает саммари встреч и задачи обычным текстом, достаёт поручения через LLM, строит план недели с учётом Google Календаря, напоминает о сроках и отвечает на вопросы по истории встреч. Данные хранятся в SQLite.

## Что умеет

| Команда | Что делает |
|---|---|
| `/start`, `/setname`, `/help` | знакомство и подсказки |
| файл `.txt` | разбор саммари встречи, задачи кнопками |
| свободный текст | новая задача, смена статуса, вопрос о встречах, история за период |
| `/tasks`, `/done` | открытые задачи, сделанное за неделю |
| `/today` | встречи из календаря, дедлайны и план на сегодня |
| `/week` | план на оставшиеся дни недели с учётом занятости в календаре |
| `/meetings`, `/review` | история встреч, итоги недели для руководителя |
| `/calendar` | подключить Google Календарь (iCal-ссылка или файл `.ics`) |
| `/stats` | личная статистика |
| `/export` | выгрузка задач и встреч в Excel |
| `/feedback` | оставить отзыв |
| `/survey` | опрос из 4 вопросов (в 19:00 бот сам предлагает его тем, кто пользуется им от 6 часов) |
| `/settings` | уведомления и напоминания после встреч |
| `/admin`, `/admin_export`, `/admin_invite` | статистика, Excel с ответами на опрос, ручная рассылка приглашения в опрос (только для `ADMIN_ID`) |

Уведомления (часовой пояс из `.env`): будни 9:00 — сводка со встречами дня (по понедельникам — итоги недели), 18:00 — напоминание о завтрашних дедлайнах, 15:00 — пинг в день дедлайна, пятница 17:00 — задачи без изменений больше 14 дней, после каждой встречи из календаря — просьба прислать саммари.

## Запуск на macOS

```bash
cd beautiful-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить токены
python bot.py
```

Переменные `.env`:

- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` — OpenAI-совместимый API (например, LLM Gateway курса и `openai/gpt-5.4-mini`)
- `TIMEZONE` — часовой пояс, по умолчанию `Asia/Tbilisi`
- `DB_PATH` — путь к базе SQLite, по умолчанию `bot.db`
- `ADMIN_ID` — ваш Telegram user_id для `/admin`

При первом запуске со старым `data.json` бот сам перенесёт данные в SQLite, а файл переименует в `data.json.migrated`.

## Деплой на Railway

Бот работает в режиме polling (сам опрашивает Telegram), поэтому публичный адрес и webhook не нужны.

1. Зарегистрируйтесь на [railway.com](https://railway.com) через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите этот репозиторий.
3. В настройках сервиса: **Settings → Source → Root Directory** = `/lab3`. Railway сам определит Python (версия из `.python-version`), установит `requirements.txt` и запустит `bot.py`.
4. **Variables → Raw Editor** — вставьте переменные из `.env` и замените путь к базе:
   ```
   DB_PATH=/data/bot.db
   ```
5. Добавьте постоянный диск: **⌘K → Volume** (или правый клик по сервису → Attach Volume), путь монтирования `/data`. Без него база будет стираться при каждом перезапуске.
6. **Остановите бота на своём компьютере** — один токен может опрашивать Telegram только из одного места, иначе будет ошибка `Conflict`.
7. Откройте **Deployments → View Logs** и дождитесь строки `Application started`.

Каждый `git push` в репозиторий автоматически пересобирает и перезапускает бота.

## Как подключить Google Календарь

1. Откройте [Google Календарь](https://calendar.google.com) в браузере.
2. ⚙️ **Настройки** → слева выберите свой календарь → **Интеграция календаря**.
3. Скопируйте **Секретный адрес в формате iCal**.
4. В боте отправьте `/calendar` и пришлите ссылку. Бот проверит её и удалит сообщение со ссылкой из чата — она даёт доступ к вашим встречам.

Если секретный адрес отключён администратором (бывает в рабочих аккаунтах), экспортируйте календарь в `.ics` (Настройки → Импорт и экспорт) и пришлите файл боту.

## Структура

- `bot.py` — запуск и регистрация обработчиков
- `handlers.py` — команды, текст, файлы, кнопки
- `llm.py` — все запросы к нейросети и промпты
- `db.py` — схема SQLite, транзакции, миграция из JSON
- `storage.py` — работа с данными пользователей, статистика, отзывы
- `calendar_service.py` — чтение iCal, повторяющиеся встречи, занятость
- `export.py` — выгрузка в Excel
- `jobs.py` — расписание уведомлений
- `keyboards.py`, `dates.py`, `config.py` — кнопки, даты, настройки
